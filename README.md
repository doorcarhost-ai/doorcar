# DoorCar

India's premium self-drive car rental platform. Book top-rated cars for hourly, daily, or weekly rentals.

## Tech stack

- **Next.js 16** (App Router)
- **React 19** + **TypeScript**
- **Tailwind CSS 4**
- **Framer Motion**
- **React Hook Form** + **Zod**
- **Radix UI** + **Zustand**

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Production build         |
| `npm start`     | Start production server  |
| `npm run lint`  | Run ESLint               |

## What's included

- Home with cinematic hero, search, categories, featured cars, offers, reviews, FAQ
- Car listing with filters and sort
- Car detail page with gallery and live price calculator
- Multi-step booking + UPI payment flow
- Trips, profile, and admin surfaces
